\# My Personal Website



This is a simple personal website created using HTML and CSS. It introduces me, Daria, a Computer Science student at the American University in Bulgaria (AUBG).



\## How the Code Works



The website consists of one main file: `index.html`.



\- \*\*HTML\*\* is used to structure the webpage. It includes headings (`<h1>`, `<h2>`) and paragraphs (`<p>`) containing information about me.

\- \*\*CSS\*\* is used to style the webpage. It adds a light purple background, purple text, and centers the content.

\- The CSS code is written inside the `<style>` section of the HTML file, so no additional files are needed.



\## How to Open the Website



\### Option 1: Open Using GitHub Pages

1\. Download or clone the GitHub repository.
